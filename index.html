About

About me

I'm Sam, a Mechatronics Engineering student (Honours Co-op) at the University of Waterloo. I like problems that sit at the border between hardware and software — making a physical system sense its environment and act on it.

My robotics work spans autonomous navigation (ROS 2, occupancy-grid mapping, LiDAR, A* planning and Pure Pursuit control), computer vision with OpenCV, and applied machine learning. Before Waterloo I founded and captained two FIRST Tech Challenge teams, leading Java software and building real-time AprilTag pose estimation for autonomous alignment.

Outside engineering I'm a professional violinist — 100+ weddings and events, a Canada's Got Talent contestant, and a music instructor. I care about building things that are precise, reliable, and worth performing.

Selected projects

Autonomous Robot Navigation Stack

Sept 2026 – Present

Modular ROS 2 navigation stack in C++ for a simulated differential-drive robot.

  • Built a real-time costmap node converting 2D LiDAR scans into occupancy grids, with obstacle inflation for safe clearance.
  • Added an odometry-driven map-memory node that fuses local costmaps into a persistent, pose-aligned global map.
  • Wrote a cost-aware A* path planner and a Pure Pursuit motion controller to compute and follow collision-free routes.
  • Ran the whole pipeline in a containerized Docker / WSL environment, visualized in Foxglove.

MP3 → Sheet Music Conversion Tool

Jun 2025 – Present

Automated ML audio pipeline that turns a song into a first-pass readable score.

  • Integrated Meta's Demucs for stem separation and Spotify's Basic-Pitch for audio-to-MIDI transcription.
  • Wrote Python processing with librosa, pretty_midi, and music21 to filter harmonic overtones, quantize beats, and render notation.
  • Used an LLM post-processing pass to flag and correct implausible notes and invalid rhythms before engraving.
  • Added a desktop launcher with a file picker so any MP3 can be dropped in and converted.
