Autonomous Robot Navigation Stack

Sept 2026 – Present

A full ROS 2 navigation stack, written in C++, that lets a simulated differential-drive robot explore an unknown space and drive itself to any point you click.

The robot starts with no map. It has to build one from live LiDAR, remember what it has seen as it moves, plan a safe route to a goal, and steer along that route in real time, with the perception, mapping, planning, and control layers all running at once and staying consistent with each other. I built each layer as its own ROS 2 node so they stay modular and communicate over topics.

data flow  →  LiDAR → costmap → map memory → planner → control → velocity commands → robot

What I built

  • Costmap node: converts each 2D LiDAR scan into an occupancy grid and inflates obstacles outward so the planner keeps real clearance for the robot's body, not just its center point.
  • Map-memory node: fuses each local costmap into a persistent global map using the robot's odometry and heading, so obstacles stay fixed in the world as the robot turns and moves.
  • A* path planner: a cost-aware search that treats cells near obstacles as expensive rather than simply blocked, so routes naturally favour open space but can still thread a tight gap.
  • Pure Pursuit controller: tracks the planned path by continuously steering toward a look-ahead point, scaling speed down through sharp turns so the robot follows curves smoothly instead of overshooting.

MP3 → Sheet Music Conversion Tool

Jun 2025 – Present

A Python tool that takes a raw MP3 and produces a first-pass piano score you can open in MuseScore.

Turning audio into notation is a genuinely hard, unsolved problem, so I built it as a chain of small stages rather than one black box. Each stage cleans up the output of the last, and because the model's raw transcription is noisy, I layered music-theory rules and an LLM review on top instead of trusting the ML blindly.

pipeline  →  stem split → audio-to-MIDI → harmonic cleanup → beat quantize → LLM review → notation

What I built

  • Model integration: chained Meta's Demucs to isolate the instrumental or vocal line, then Spotify's Basic-Pitch to transcribe that stem into MIDI, bounded to piano range.
  • Music-theory cleanup: wrote logic in pretty_midi and librosa to strip harmonic overtones (false notes an octave or fifth above a real one), snap note onsets to detected beats, and auto-detect key and clefs in music21.
  • LLM correction pass: export the score to MusicXML, have a model flag implausible notes and bad rhythms, and return structured JSON edits (delete or transpose) that get applied to the score automatically, not just read as advice.
  • Desktop launcher: added a simple file-picker app so any MP3 can be dropped in and converted without touching the code.
